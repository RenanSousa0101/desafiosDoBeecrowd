# 🧮 Desafios do Beecrowd

Este repositório contém a minha coleção de soluções para os problemas propostos na plataforma [Beecrowd](https://www.beecrowd.com.br/), voltada ao aperfeiçoamento da lógica de programação e resolução de algoritmos.

As soluções estão organizadas por categorias e dificuldades, com foco em boas práticas de código e clareza na implementação.
